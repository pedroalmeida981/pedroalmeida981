## How I approach quality

1. Understand the user journey, acceptance criteria, and product risks.
2. Prioritise important flows, boundary conditions, and accessibility barriers.
3. Combine structured test design with hands-on exploration.
4. Report defects with concise reproduction steps and useful evidence.
5. Re-test fixes, communicate residual risks, and look for opportunities to automate repeatable checks.
